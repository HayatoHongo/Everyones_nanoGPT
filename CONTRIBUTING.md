# Contributing

Thank you for your interest in this repository.

This project is mainly developed and maintained by an internal, in-person community: the U-Tokyo Student AI Society.

At this stage, our internal handover and maintenance process is still developing. Because of this, we do not currently have enough capacity to actively accept external contributions.

Please do not open Pull Requests for small changes such as typo fixes or minor wording improvements. We may not be able to review or respond to them.

This repository is translated with GPT-5, so Pull Requests for translation mistakes are welcome.

If you find a critical technical mistake, please report it by opening an Issue.

For now, we need to prioritize improving our internal handover and maintenance process before accepting broader external contributions.

Thank you for your understanding.
